# 管理员使用统计

管理员打开 `/myclass/admin.html`，登录后进入“使用统计”。普通账号既不显示此标签，也无权访问 `/myclass/api/admin/usage`。

## 数据与口径

- 支持近 7 / 30 / 90 天、自选日期（最多 366 天）、用户名筛选和当前筛选明细 CSV 导出。
- 服务端按北京时间保存每日聚合，统计成功登录、课堂连接、成功转发的投屏打开、WebRTC 协商、成功上传与抽选完成；旧 Android 和 iOS 使用现有接口即可纳入。
- 活跃账号指当日发生任一已记录行为的已识别账号，包括管理员和期间使用后被删除的账号。未登录设备单列，不计入活跃账号数；无行为的现有教师也显示，方便发现未使用账号。
- 连接包含重连；投屏打开包含重复打开，不代表教学节数或完成播放；WebRTC 协商包含重新协商，不能据此区分摄像头与屏幕投屏。翻页、画笔、心跳不计数。
- 文件、链接上传按同账号同日返回的课件 ID 去重；上传大小是原始文件大小，链接为零。抽选完成按房间恢复标识及请求 ID 同日去重。
- 当前在线教师账号、大屏数量为查询时快照，不受日期影响。不推算授课时长。
- 管理员“使用统计”中的“当前在线教师”按课堂连接列出账号、角色、连接码和大屏状态，点击“查询 / 刷新”更新。同一账号连接多间教室时分别显示；未登录设备单列，账号数按已识别账号去重。大屏断线重连期间仍显示在线教师设备，不把仅登录管理页的账号视为课堂在线。不返回 token、密码或房间恢复密钥。
- 从首次启动统计模块开始记录，页面显示开始时间；没有行为历史的数据不倒推。用户重命名显示当前用户名，已删除用户保留历史计数。

## 存储与部署

数据位于 `server/data/usage/meta.json` 和 `server/data/usage/YYYY-MM-DD.json`，不入 Git，需随 `server/data/` 一起备份。按日聚合，保存账号 ID、用户名、计数、最后事件时间及去重散列，不保存 token、密码、IP、文件地址、学生信息或原始消息。

写入串行排队、临时文件 fsync 后原子替换；采集失败记录服务器日志，不阻塞或拒绝登录、上传、投屏。无自动清理策略，历史按日保留。异常停机可能丢失尚在内存队列中的最后几条事件；该页面用于使用概览，不作为计费或考勤凭证。

部署需要同步 `usageStore.js`、`roomManager.js`、`server.js` 和管理员页面资源，然后重启 Node 服务。Android 安装包不需为统计重新构建。管理员资源带独立缓存版本；旧协议与数据接口格式不变。

验证：`cd server && node --test`，覆盖并发写入、重启保留、北京时间跨日、去重、损坏数据保护、权限校验和记录失败时投屏仍可用。浏览器验证日期筛选、搜索与 CSV 导出。
