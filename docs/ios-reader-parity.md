# iOS 课件交互与 Android 对齐

- 连接课堂后可选择锁定横屏、自动感应、锁定竖屏，保存偏好；断开后恢复跟随设备。Safari 使用应用界面旋转，触摸、画笔和范围框坐标同时转换，不依赖浏览器的系统方向锁定 API。
- 列表缩略图为 96×54（16:9），完整容纳页面。点击缩略图进入独立连续文档预览；点击课件标题沿用播放入口。
- 连续预览按原始幻灯片显示每页最后一个动画状态，跳过隐藏页。只渲染可见页，顺序执行，离屏画布缓存上限 24 MB；预览不发送课堂消息。
- 快速翻页取代页码输入框：拖动滑块预览最终动画状态，松手跳到所选原始页的第一个状态，取消不改变大屏。
- 竖屏播放使用固定工具区与可收缩舞台，短屏下工具区可滚动，避免 A4 课件挤出底部按钮。
- Android、大屏和服务器通信逻辑不变，没有新增消息或字段。共享页码模块仅增加分组辅助函数；链接模块的几何获取参数保留原有默认行为。

## 验证

```powershell
node scripts/test-ios-reader.cjs
$env:MYCLASS_WEBKIT='1'
node scripts/test-ios-reader.cjs
```

测试使用 Playwright、隔离服务器和测试数据，覆盖 390×844、375×568、768×1024、844×390、1180×820。检查方向偏好、16:9 比例、连续预览最终状态、原始页映射、快速翻页的预览与提交、取消、独立预览不发送信令、A4 控件边界及旋转后的真实指针笔迹坐标。截图在系统临时目录 `myclass-ios-reader-proof`。

Windows WebKit 不提供 WebRTC，WebKit 测试中的大屏由 Edge 运行，iOS 页面由 WebKit 运行。浏览器自动化不能替代真机 Safari/PWA 对系统旋转、安全区、Apple Pencil 和原生滑块触摸的验证。
