# 大屏红外触控书写优化与验证

日期：2026-10-24。范围：Web 大屏的课件标注和电子黑板。

## 改动

- 校准坐标同时应用到 PointerEvent 合并采样点，避免起笔、行笔使用不同坐标。
- 黑板补齐合并采样；两种画布保留抬笔位置，以屏幕距离过滤小于 0.5 CSS 像素的重复采样。
- 无压感输入使用等宽二次曲线。固定曲线段分别绘制，避免延长整条路径时浏览器重新计算前半段抗锯齿造成闪动。压感数据及旧笔迹的渲染兼容分支保留。
- 高频本地输入合并到动画帧；完成的笔迹缓存为离屏画布。撤销、清空、页面、视口、圈选编辑等仍触发重建，板擦保持原有合成顺序。
- 课件同步发送全部合并采样点，避免保存/回放时退化为稀疏折线。
- 更新页面脚本版本参数，使浏览器重新获取脚本。

## 验证

使用本机 Edge 无头浏览器、Playwright 和隔离测试服务。

| 检查 | 结果 |
| --- | --- |

| 同一专项中的密集笔迹测试 | 课件标注和黑板各 400 笔、共 60,000 个历史点；同一帧内 30 次移动只绘制 1 次活动笔画，历史笔画重新绘制次数为 0。 |

## 已有测试限制

另外执行的两个旧脚本未通过。使用 `git show HEAD:web/app.js` / `touchCalibration.js` 将浏览器资源替换为修改前版本复核，两者出现相同失败：

- `scripts/test-touch-calibration.cjs`：假定直线按钮右侧的偏移触点落在禁用撤销按钮上，当前工具栏布局下该假定不成立。失败位置为 `disabledHit === true`。
