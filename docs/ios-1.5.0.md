# iOS 1.5.0（2026101201）

- 拍照 / 相册文件按 MIME 和扩展名识别，包含 HEIC/HEIF、无扩展名图片。选择器优先请求兼容图片格式；浏览器可解码的照片统一转换为 JPEG，文件名与实际编码一致，手机预览复用转换后的图片。
- 图片转换串行执行、限制长边 1920，使用 Blob 避免 Base64 的额外内存；转换失败、超时、取消均给出明确结果。系统相机返回时课堂暂时断线不再丢弃照片，上传结果保留并在重连后投屏。
- 前台选中与后台预上传复用同一任务；重试使用稳定上传编号，取消检查覆盖转换与上传阶段。
- 图片 / 视频和课件列表增加按可见区域加载的缩略图，最多同时处理两项。图片填充正方形，视频截取开头画面，PDF / 转换后的 Office 课件显示服务器保存的上次播放页。
- 课件按钮背景显示播放进度，附上次页码 / 总页数和百分比，数据来自现有服务器接口。PPT 动画状态用于实际渲染页，展示页码按转换映射还原。
- 新 iOS 页面、模块和 Service Worker 统一更新缓存版本；Android / 大屏协议及服务端数据结构不变。

验证：服务端及新增回归测试 55 通过 / 1 跳过（LibreOffice 集成用例）；隔离浏览器验证相册与拍照文件入口、JPEG 上传和投屏信令、图片 / 视频封面、PDF 第二页缩略图、2/3 页进度、长列表滚动加载。尚未在真实 iPhone / iPad Safari 上验证系统相机与 HEIC 解码；旧 Safari 无法解码的 HEIC 会明确提示转为 JPEG。
