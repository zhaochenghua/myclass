## 二、你需要补充的信息

以下内容在 `01_软件著作权登记申请表（填写稿）.docx` 和 `03_软件说明书...docx` 中以【】标出，
提交前请替换为真实信息：

1. 姓名（与身份证一致）
2. 18 位身份证号码
3. 详细联系地址、邮政编码
4. 手机号码、电子邮箱
5. 省份 / 城市（如不是“浙江省 / 宁波市”）
6. 说明书封面“著作权人”和“编制人”

身份证号、手机号等敏感信息建议直接在 Word 中填写，不要通过聊天工具发送。

## 三、办理顺序

1. 打开 <https://register.ccopyright.com.cn/>，注册“自然人”账号并完成实名认证。
2. 按 `01_...申请表（填写稿）.docx` 在系统中逐项填报。
3. 系统生成“申请确认签章页”，打印后本人手写签名，再扫描为 PDF。
4. 上传签章页、身份证正反面、`02_...源程序....pdf`、`03_...软件说明书....pdf`。
5. 提交后等待受理和审查（法定时限为受理之日起 60 日）。
6. 审查通过后登录用户中心下载电子证书。

## 四、必须确认的两件事

**1. 发表状态。** 当前材料按“未发表”准备。如果软件已经公开下载、对外提供安装包或在
校外实际使用，应改为“已发表”，并填写首次发表日期和地点；否则可能被认定为申请信息不实。

**2. 权属。** 当前按“个人独立开发、非职务作品”准备。如果软件是执行学校工作任务、主要利用
学校物质技术条件开发，著作权可能归学校所有。以个人名义申请前，应确认不属于职务开发；
必要时由学校出具非职务开发证明，或改为以学校名义申请。

## 五、重新生成

材料由 `tools/copyright/` 下的 Python 脚本生成，修改内容后可重新运行：

```powershell
$py = "C:\Users\zch\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py tools\copyright\make_assets.py
& $py tools\copyright\build_source_doc.py
& $py tools\copyright\build_manual.py
& $py tools\copyright\build_forms.py
```

导出 PDF（需要本机安装 Microsoft Word）：

```powershell
& tools\copyright\finalize_docx.ps1 -Docx "软著申请材料\03_软件说明书_MyClass教师投屏系统V1.0.docx" -Pdf "软著申请材料\PDF\03_软件说明书_MyClass教师投屏系统V1.0.pdf"
```
